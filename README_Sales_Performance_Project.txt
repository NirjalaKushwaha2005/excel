SALES PERFORMANCE PIVOT TABLE DASHBOARD
=========================================

Course: Week 1 - Excel & Data Fundamentals

Requirements:
1. Total Revenue
2. Sales by Category
3. Yearly Sales Trends
4. Department-wise Revenue

Workbook structure:
- Dashboard: final visual dashboard
- Pivot Analysis: four required analysis tables
- Project Notes: project documentation
- Orders / Returns / People: original source data

Important:
The supplied Orders dataset does not contain a Department column.
It contains Category and Sub-Category. Therefore, Sub-Category is used
as the Department-wise Revenue breakdown without inventing data.

Main metric:
Sales is used as the Revenue/Sales measure.
