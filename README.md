# Sales Performance Pivot Dashboard

## Project Overview

This project analyzes sales data using Microsoft Excel to understand overall sales performance and identify important sales trends.

The project uses Pivot Table-style analysis and a dashboard to summarize the data in a clear and interactive way.

## Objectives

The main objectives of this project are:

- Calculate Total Revenue
- Analyze Sales by Category
- Analyze Yearly Sales Trends
- Analyze Department-wise Revenue
- Present the results through a sales performance dashboard

## Analysis Performed

### 1. Total Revenue
Calculated the total revenue generated from all sales records.

### 2. Sales by Category
Analyzed total sales for each product category to understand which categories contribute to overall revenue.

### 3. Yearly Sales Trends
Grouped the Order Date by year and analyzed how sales changed over different years.

### 4. Department-wise Revenue
Analyzed revenue across product sub-categories to compare the performance of different departments.

## Tools Used

- Microsoft Excel
- Pivot Table-style data analysis
- Charts and dashboard visualization

The dashboard provides a summarized view of sales performance and helps identify revenue patterns across categories, years, and departments.
